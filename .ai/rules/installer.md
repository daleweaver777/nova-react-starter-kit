# Installer

## Keep npm in the kit's Composer scripts and remove the hook's node_modules

This applies to the starter kit. A generated application has already been rewritten for its selected package manager and should keep that result.

Chisel chooses the install hook's package manager from the `setup` and `dev` Composer scripts. Keep those scripts saying `npm`: the Laravel installer rewrites the literal tokens `npm`, `npx` and `ppnpm` for the chosen manager, and npm is available wherever Node is installed.

The feature-install hook runs before `laravel new` chooses its final package manager. The installer removes a foreign lockfile but not the npm-created `node_modules`, so pnpm, Yarn or Bun can otherwise install over npm's flat tree and leave stale declarations behind. Keep `InstallFeaturesCommand::removeNodeModules()` after the hook build so the installer's package manager starts clean.

## Installation examples include --boost

The `.ai/rules` directory is discovered through the agent instructions generated by Laravel Boost. Keep `--boost` in the README installation examples. This repository also carries a minimal `AGENTS.md` router so agents working directly on the starter kit load the same rules before Boost exists.
